## ⚙️ How It Works

### **Every 3 Hours (Not 4):**

**Screening Process:**
1. Scan all tickers with adaptive thresholds
2. Find candidates matching criteria
3. **Check for URGENT criteria:**
   ```
   IF score >= 85
   AND daily_change >= 8%
   AND volume >= 3x average
   AND has_major_catalyst
   AND not_alerted_in_last_24h
   THEN → IMMEDIATE EMAIL
   ELSE → Add to weekly summary
   ```

### **Spam Prevention:**

**Max 2 urgent alerts per day**
- Even if 5 opportunities are "urgent"
- Only top 2 get immediate email
- Others wait for Sunday summary

**24-hour duplicate filter**
- Same ticker can't trigger twice in 24h
- Prevents alert spam on same stock

## ⚙️ Customization

### **Too Many Urgent Alerts?**

Tighten criteria in `config_autonomous_hybrid.yaml`:
```yaml
urgent_criteria:
  min_score: 90              # Stricter (was 85)
  min_daily_change: 10.0     # Higher (was 8%)
  min_volume_multiplier: 4.0 # More unusual (was 3x)
  max_per_day: 1             # One max (was 2)
```

### **Missing Urgent Opportunities?**

Loosen criteria:
```yaml
urgent_criteria:
  min_score: 80              # Lower (was 85)
  min_daily_change: 6.0      # Lower (was 8%)
  min_volume_multiplier: 2.5 # Less strict (was 3x)
  max_per_day: 3             # More allowed (was 2)
```

### **Add Custom Urgent Keywords:**

```yaml
urgent_catalyst_keywords:
  - "your custom keyword"
  - "specific catalyst you care about"
```
